# React Port of Vue.js Drill Platform

This directory contains the React port of the Vue.js Drill application.

## Structure

```
react/
├── src/
│   ├── components/
│   │   └── CoreModule/
│   ├── views/
│   ├── hooks/
│   ├── context/
│   └── utils/
├── public/
└── package.json
```

## Status

Currently porting the DrillPlatform and Drill components from Vue.js to React.

## Notes

- Using React Hooks for state management
- Material-UI (MUI) for UI components (replacing Vuetify)
- React Context API for global state (replacing Vuex)
- react-i18next for internationalization (replacing vue-i18n)
